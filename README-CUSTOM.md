# Quick installation and rollback

This is the Top Right Edition of SpaceTheme, maintained at
https://github.com/w-rakeeb/SpaceTheme-Steam.

See [README.md](README.md) for screenshots, features and full installation steps,
[docs/CHANGES.md](docs/CHANGES.md) for the source change map, and
[docs/VALIDATION.md](docs/VALIDATION.md) for checks and limitations.

## Install

1. Exit Steam and back up its current theme folder and Millennium configuration.
2. Copy the release archive's `Steam` folder into `<Steam>/millennium/themes/`.
3. Start Steam and select SpaceTheme for Steam in Millennium.
4. Choose General > Userpanel > Userpanel position > Top right.

The reload button refreshes Steam's interface. Storage opens native Steam Storage
settings. News, Notifications and Friends remain visible. Other controls open in
the leftward dropdown on compact windows. Size on Disk is not included.

## Rollback

Exit Steam and restore the backed-up theme folder and config. For the original
profile position only, choose Sidebar (original) in theme settings and reload.
